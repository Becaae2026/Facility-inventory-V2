Connection

Web App URL is read from config.js (kept separate so dashboard updates never wipe it).

To change the URL: edit config.js in the GitHub repo and commit. Auto-refresh: every seconds (edit in config.js). Changes made directly in the Google Sheet appear here on the next refresh; changes made here are written straight into the Sheet.

Items — add / edit

The item code (next FAC-…) is assigned automatically and the row is written to the Item Master tab.

Vendors — add / edit

Branches / departments — add / edit

Departments are saved without a code, same as the existing ones in the Branches tab. Deleting is admin-only; past transactions always keep their names.

Stock adjustment (admin only)

Select an item to see its current balances.

Add / Remove creates an ADJ-… entry in Stock IN / Stock OUT (never deleted, voidable like any document). Set opening rewrites the Opening qty in Item Master. Every adjustment is written to the Audit Log with your username and reason.

Users (admin only)

UsernameRole

Changes apply immediately — a removed user is blocked on their very next action. You cannot remove yourself or the last admin. Every add/remove is written to the Audit Log.

Data protection

Transactions are never deleted — cancelling sets the status to VOID and the row stays in the Sheet. Every action is written to the Audit Log tab. A daily copy of the workbook is saved to the Drive folder Facility Inventory Backups with 5-year retention (see SETUP.md).
